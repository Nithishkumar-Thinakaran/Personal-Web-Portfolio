# Portfolio Website — Nithishkumar Thinakaran

Welcome to my personal portfolio website! 🌐

Built using React + Vite, this portfolio showcases my projects, technical skills, internships, and professional journey as a Full-Stack Developer and Computer Science Postgraduate.

## Features

* Responsive modern design
* Project showcase
* Skills & technologies section
* Experience timeline
* Contact form integration
* GitHub Pages deployment

## Run Locally

```bash
git clone https://github.com/Nithishkumar-Thinakaran/portofolio.git

cd portofolio

npm install

npm run dev
```
